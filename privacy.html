Privacy Policy

Finance Recap Uploader · Last updated: October 27, 2026

Who uses this app

Finance Recap Uploader is a private tool. Its only user is the owner of the YouTube channel Justin Talks Wealth. It is not offered to the public.

What data it uses

When the channel owner signs in with Google, the app gets permission to use these YouTube services for that one channel:

  • YouTube Data API: upload the channel's videos, set their title, description, captions and thumbnail, and read the channel's own video list.
  • YouTube Analytics API: read the channel's own video statistics (for example views and how long people watched).

It does not read any other person's data, and it does not use the data for advertising.

Where the data is kept

The sign-in token and the statistics stay on the channel owner's own computer. Nothing is sent to anyone other than Google's own YouTube services. The data is never sold or shared.

Google and YouTube policies

This app uses YouTube API Services. By using it you agree to the YouTube Terms of Service. Google's use of data is covered by the Google Privacy Policy.

The app's use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

How to remove access

The channel owner can remove the app's access at any time at myaccount.google.com/permissions (or the Google security settings page). Deleting the token file on the owner's computer also removes it from the app.
