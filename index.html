Finance Recap Uploader

This is the home page of Finance Recap Uploader, a private tool used only by the owner of the YouTube channel Justin Talks Wealth.

The tool runs on the channel owner's own computer. With the owner's permission (Google sign-in), it uses the YouTube Data API and the YouTube Analytics API to:

  • upload the channel's own finance videos and set their title, description, captions and thumbnail;
  • read the channel's own video statistics, so the owner can see which videos worked.

It is not offered to the public, and nobody else can sign in to it or use it.
